# tgs — published output

Generated store data for The Green Solution (hours, phones, JSON-LD), written
by the sync workflow and served by GitHub Pages. Do not edit by hand — every
file here is regenerated on each sync. This README also bootstraps the
directory so the config test suite passes before the brand's first sync.

tgscolorado.com is not a Webflow site: it reads `stores.json` from here while
it renders, and nothing is written to a CMS.
